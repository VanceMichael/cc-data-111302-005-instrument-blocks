# 成组采集契约

采集站通过 TCP 网关从台式测量仪成组采集读数。一组读数绑定本组确认过的通道配置与单位; 读数完整并校验通过后才对下游开放。本文档是 `src/acquire.mjs`(核心)、`src/acquisition-http.mjs`(值班接口)的语义约定。

## 帧规则(网关协议)

- 命令: 一行文本, 以 LF 结束。
- 普通回答: 以 LF 结束的文本行, 可能分任意多片到达, 按 LF 重组。
- 定长二进制块: `#<位数><长度><负载>`, 可选跟一个 LF 结束符。**块的边界只由块头声明的长度决定**, 不用读超时或换行猜边界(负载里可能含 `0x0A`)。每条命令的超时只是活性保护; 超时或断线后放弃连接, 不在旧连接上继续猜帧。
- 异步通知: 以 `!` 开头的行(如 `!STATUS 1`), 由设备主动插入。**通知单独上报, 不占用下一条命令的回答位置**; 未请求的回答记为协议异常。

## 命令与回答对应

一条连接上命令串行发出, 每条命令恰好消费一个回答(文本行或定长块)。`CONF:UNIT`/`INIT`/`*IDN?`/`STAT?` 期望文本行, `FETCH?` 期望定长块; 仪器回 `ERR ...` 行记为仪器拒绝。

## 成组采集序列与配置依据

`runGroup` 在设备锁内依次执行: `*IDN?`(型号) → `STAT?`(世代) → `CONF:UNIT`(确认单位) → `INIT`(触发, 得到本组触发号) → `FETCH?`(取定长块) → `STAT?`(复核)。每组记录:

- `basis`: 型号、世代、确认单位、触发号 —— 本组读数的配置依据;
- `blocks`: 原始块(头、长度、SHA-256、base64、接收时间), 先落账再校验;
- `progress`: 各阶段接收进度; 断线时异常上带解析器进度(如 `块 20 字节已收 9`);
- `notifications` / `exceptions`: 异步通知与异常全程留痕。

校验(任一不符即失败, 不开放读数): 块长度须为 16 字节(2 个 float64 大端); 仪器世代未变(未复位); 仪器触发号等于本组触发号(未被后续触发覆盖); 仪器记录的触发时单位等于本组确认单位(不被并行改单位误标)。

## 组状态与值班三态

```
created → configured → pending ──校验通过──→ completed
                         │                       (released, 对下游开放)
                         ├─校验失败/不可恢复──→ failed
                         └─断线等可恢复异常──→ 保持 pending
```

值班视图 `measurement` 三态: `none` 没有测量 / `pending` 结果待确认 / `completed` 已完成。映射: 仅 `completed` → 已完成; `pending` → 结果待确认(触发已确认、结果未读完或未校验); 其余(含失败终态)→ 没有测量, 详情看 `exceptions`。

## 断线恢复

`recoverGroup` 只补读未读完的结果, **绝不重发 INIT**, 不把两次测量合为一次:

- 世代变了(设备复位) → 判 `failed`, 测量状态"没有测量", 不自动补发触发;
- 触发号被后续触发覆盖 → 判 `failed`, 拒绝把别人的测量并入本组;
- 触发号与单位都和本组确认依据一致 → `FETCH?` 补读, 复核通过后 `completed` 开放。

组状态随审计日志(默认 `.local/acquisition-journal.jsonl`)持久化, 服务重启后值班仍看到"结果待确认", 可继续恢复。

## 互斥与停止

设备锁是带租约的互斥锁: 同一时刻只有一个作业执行"配置+触发+读取"; 第二个作业立即得到 `BusyError`(HTTP 409), 不排队穿插。`stop()` 中止在途命令并强制放锁; 租约到期也自动释放 —— 停止采集不会把设备永远锁住。被停止的组若已触发, 保持"结果待确认", 之后可恢复。

## HTTP 接口(值班人员)

采集结果(含失败)是数据, 用 200 返回组记录; 只有调用本身有问题才用 4xx。

| 方法与路径 | 说明 |
| --- | --- |
| `GET /health` | 存活检查 |
| `GET /lock` | 设备锁状态(持有者、租约到期时间) |
| `GET /labels` | 三态中文标签 |
| `POST /groups` `{unit, owner?}` | 执行一组采集, 返回组记录 |
| `GET /groups` | 组摘要列表(含三态) |
| `GET /groups/:id` | 组全量记录(依据/原始块/进度/异常) |
| `POST /groups/:id/recover` | 恢复待确认的组(不重发触发) |
| `GET /groups/:id/result` | 下游取数; 未完成或校验未过返回 409 与当前三态 |
| `POST /stop` | 停止采集并放开设备锁 |

错误映射: `BusyError`/`StateConflictError` → 409, `NotFoundError` → 404, `ClientInputError` → 400。

启动: `npm run start:acquisition`, 用 `GATEWAY_HOST`/`GATEWAY_PORT` 或 `SOURCE_URL` 指定网关, `JOURNAL` 指定审计日志路径, `HOST`/`PORT` 指定监听, `LOCK_TTL_MS` 指定锁租约。

## 恢复行为演示

`npm run demo:recovery` 用来源的 `/control` 开关演示: 正常成组、异步通知旁路、截断断线→待确认→补读恢复(触发号不变)、复位→没有测量、同事改单位(触发前→校验失败; 触发后→不误标)、同事抢触发→拒绝合并、停止→放锁。不接真实仪器, 不做波形分析。
